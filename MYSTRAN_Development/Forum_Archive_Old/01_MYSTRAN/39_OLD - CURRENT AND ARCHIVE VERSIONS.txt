Notable Modifications from the prior official version:
- Corrected error for the BUSH element and other more minor changes.
- Introduced the new MYSTRAN Benchmark Tool in the Test Runs ZIP

Additional files not commonly used by end users:
Source Code (in Zip Form as opposed to GitHub form - direct download) -  https://www.mystran.com/versions/MYSTRAN...Source.zip

Version 12.0
Windows EXE - https://www.mystran.com/versions/MYSTRAN_12.0A.zip - Compiled with Option 1 (Preferred)
Windows EXE - https://www.mystran.com/versions/MYSTRAN_12.0B.zip - Compiled with Option 2 (Alternate) from the compile thread using CodeBlocks and gFortran (10.2.0 x64) and SuperLU version 5.2.2
Linux - See the preferred option in this thread: https://www.mystran.com/forums/showthread.php?tid=2
Documentation - https://www.mystran.com/documentation/MY...9_2021.zip
Test Runs (used to benchmark) - https://www.mystran.com/versions/MYSTRAN...stRuns.zip - Note that starting with 12.0, the Test Runs have been updated to be in sync with gFortran

Notable Modifications from the prior official version:
- Added the SuperLU sparse solver. Previously there was only an option to use the LAPACK banded solver. The sparse solver is more efficient and necessary for problems with a larger number of DOF.
